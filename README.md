# Chess Telegram CRM

Telegram-бот для отслеживания активности шахматистов на Lichess и Stepchess с интеграцией в Firestore.

## Возможности бота
- **Управление учениками**: Добавление, поиск, редактирование профилей, удаление.
- **Интеграция с Lichess**:
  - Сбор рейтингов по всем дисциплинам (Рапид, Блиц, Пуля, Классика, Задачи).
  - Сбор показателей по тактическим режимам (Storm, Racer, Streak).
  - Расчет очков за участие в месячных и годовых турнирах (с учетом групп и коэффициентов).
- **Интеграция со Stepchess**:
  - Статистика по решенным задачам за выбранный период (количество, попытки, затраченное время).
  - Результаты контрольных тестов с указанием максимального числа решенных задач (из 10) и количества попыток.
  - Результаты экзаменов.
- **Интеграция с ФШР и ФИДЕ**:
  - Парсинг рейтингов по классике, рапиду и блицу на основе ID игрока.
- **Спортивные разряды**:
  - Поддержка разрядов: КМС, 1-й/2-й/3-й спортивные разряды, 1-й/2-й/3-й юношеские разряды.
  - Отображение разряда в карточке ученика и быстрое редактирование кнопками.
  - Генерация списков рейтингов, отфильтрованных по разрядам.
- **Учебные группы и возраст**:
  - Автоматический расчет точного возраста ученика.
  - Расчет учебных групп (Утренняя/Вечерняя лига) на основе возраста и рейтинга.
- **Отчеты об активности**:
  - Генерация сводных отчетов по активности за день, 3 дня или 7 дней.
  - Построение лидербордов (рейтинговых таблиц) по Lichess, ФШР, ФИДЕ.

## Структура базы данных и собираемые данные

База данных Firestore настраивается автоматически (коллекция `students`). Никаких ручных таблиц создавать не нужно, структура формируется при добавлении учеников.

Для каждого ученика хранятся следующие данные:
- **Личная информация**: ФИО, дата рождения, возраст, город.
- **Профили**: ID ФШР, ID ФИДЕ, ник на Lichess, ID на Stepchess.
- **История турниров**: Очки и коэффициенты за участие в годовых/месячных соревнованиях.
- **Рейтинги**:
  - Lichess (классика, рапид, блиц, пуля и т.д. + калибровочные флаги `?`).
  - ФШР (классика, рапид, блиц).
  - ФИДЕ (классика, рапид, блиц).
- **Лиги**: Группа Утро, Группа Вечер (расчитываются автоматически).

## Локальный запуск

### 1. Настройка базы данных (Firebase/Firestore)
1. Перейдите в [Firebase Console](https://console.firebase.google.com/).
2. Создайте новый проект.
3. Перейдите в **Firestore Database** и создайте базу данных.
4. Перейдите в **Project Settings** -> **Service accounts** (Параметры проекта -> Сервисные аккаунты).
5. Нажмите **Generate new private key** (Создать новый закрытый ключ).
6. Скачайте JSON-файл ключа.
7. Переименуйте скачанный файл в `serviceAccountKey.json` и сохраните его в папку `data/` в корне проекта.

### 2. Настройка Telegram-бота
1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram и скопируйте токен.
2. Узнайте свой Telegram ID (например, через бот [@userinfobot](https://t.me/userinfobot)) для указания в качестве администратора.

### 3. Конфигурация окружения
1. Скопируйте файл `.env.example` под именем `.env`:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` и впишите ваши параметры:
   - `TELEGRAM_BOT_TOKEN`: токен вашего бота.
   - `ADMIN_TELEGRAM_ID`: ваш Telegram ID.
   - `LICHESS_API_TOKEN`: ваш токен Lichess (опционально).

### 4. Установка зависимостей и запуск
1. Установите библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите бота:
   ```bash
   python -m app.main
   ```

## Импорт списка учеников (опционально)
Вы можете массово загрузить список учеников с помощью скрипта `scripts/import_data.py`:
1. Подготовьте файл `пример.txt` в формате TSV (значения, разделенные табуляцией, можно экспортировать из Excel).
2. Заголовки столбцов должны быть следующими:
   `ФИО`, `Дата рождения`, `ФШР id`, `ФИДЕ id`, `Город, район`, `Lichess`, `Stepchess`, `Рапид рейтинг`
3. Положите файл в корень проекта.
4. Запустите импорт:
   ```bash
   python scripts/import_data.py
   ```

## Деплой в Google Cloud Run

### 1. Подготовка Google Cloud
1. Установите [Google Cloud CLI](https://cloud.google.com/sdk/docs/install).
2. Авторизуйтесь в терминале:
   ```bash
   gcloud auth login
   ```
3. Выберите нужный проект:
   ```bash
   gcloud config set project ИДЕНТИФИКАТОР_ПРОЕКТА
   ```

### 2. Настройка переменных окружения в GCP
В Google Cloud файл `.env` не заливается. Добавьте переменные через интерфейс Cloud Run в разделе **Configuration** -> **Variables & Secrets**:
- `TELEGRAM_BOT_TOKEN`
- `ADMIN_TELEGRAM_ID`
- `LICHESS_API_TOKEN`

### 3. Настройка доступа к Firestore
Файл `serviceAccountKey.json` в Cloud Run не нужен.
1. В консоли GCP откройте раздел **IAM & Admin**.
2. Найдите **Default Compute Service Account** (аккаунт, под которым крутится Cloud Run).
3. Добавьте ему роль **Cloud Datastore User** для доступа к Firestore.

### 4. Запуск деплоя
Запустите команду в корне проекта:
```bash
gcloud run deploy chess-crm-bot --source . --region europe-west1 --allow-unauthenticated
```
